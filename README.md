## Overview

**Rav 365 Photo Editor** is a professional Windows desktop photo editing application designed to provide a fast, intuitive, and feature-rich editing experience.

Built with **Flutter**, the application combines a modern desktop interface with powerful editing tools, making it suitable for photographers, graphic designers, digital artists, students, businesses, and content creators.

The goal of Rav 365 is to deliver a premium editing experience while remaining lightweight, responsive, and easy to use.

# Getting Started

## Prerequisites

Make sure you have:

* Flutter SDK
* Dart SDK
* Windows 10 or later
* Visual Studio with Desktop C++ tools

---

## Clone the Repository

```bash
git clone https://github.com/yourusername/rav_365_photo_editor.git
```

---

## Navigate to the Project

```bash
cd rav_365_photo_editor
```

---

## Install Dependencies

```bash
flutter pub get
```

---

## Run the Application

```bash
flutter run -d windows
```
